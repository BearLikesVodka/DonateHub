# Цель донатов для OBS: DonationAlerts + DonateX

Одна полоса сбора, в которую одновременно идут донаты с DonationAlerts и DonateX.
Внешний вид настраивается на странице с живым превью, завершённые сборы сохраняются в историю.

## Установка и запуск

Нужен [uv](https://docs.astral.sh/uv/). Python 3.15 uv скачает сам.

```sh
uv sync
uv run python -m donation_goal
```

- Настройки: <http://127.0.0.1:8000/>
- Оверлей для OBS: <http://127.0.0.1:8000/overlay>

Данные (цели, донаты, токены) хранятся в `data/app.db` в той папке, откуда запущен сервер.
Сервер должен работать, пока идёт стрим.

## Подключение платформ

Всё делается на вкладке «Подключения».

**DonateX.** Скопируйте токен из кабинета DonateX (Настройки → API и доступ), вставьте и сохраните.

**DonationAlerts.**
1. Откройте <https://www.donationalerts.com/application/clients> и создайте приложение.
2. В поле Redirect URL укажите `http://127.0.0.1:8000/auth/da/callback`.
3. Вставьте ID приложения и API ключ на странице настроек и сохраните.
4. Нажмите «Войти через DonationAlerts» и разрешите доступ.

Когда платформа подключена, рядом с ней горит зелёный «Подключено». После обрыва связи сервер
переподключается сам и подтягивает донаты, пропущенные за это время.

## Добавление в OBS

Источники → «+» → «Браузер», URL `http://127.0.0.1:8000/overlay`, ширина 800, высота 200.
Все размеры виджета задаются в `vw`, поэтому он масштабируется вместе с источником.

## Как считается сумма

- В цель идут донаты с обеих платформ с даты старта до даты окончания (или до завершения сбора).
- Суммы в рублях. DonateX сам присылает сумму в рублях. Донаты DonationAlerts в другой валюте
  пересчитываются по курсу ЦБ на день получения.
- Тестовые донаты DonateX в сумму не идут.
- Для денег, пришедших мимо платформ, есть ручная корректировка на вкладке «Текущая цель».
