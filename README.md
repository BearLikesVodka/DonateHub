# DonateHub

Десктоп-приложение для стримеров, которые принимают донаты и общаются со зрителями на нескольких платформах сразу.
DonateHub собирает события с DonationAlerts, DonateX и других сервисов в одно место и отдаёт в OBS общие виджеты:
цель сбора, ленту донатов, очередь оповещений, мультичат.

Сейчас готова **общая цель донатов** для DonationAlerts и DonateX. Остальное в работе, см. [дорожную карту](#дорожная-карта).

## Что уже работает (v0.2.0)

- Одна полоса сбора для OBS, в которую одновременно идут донаты с DonationAlerts и DonateX.
- Настройка внешнего вида с живым превью: готовые стили, 36 шрифтов Google Fonts, цвета, обводки, тени.
- Даты старта и окончания сбора, ручная корректировка суммы, история завершённых сборов.
- Пересчёт валют в рубли по курсу ЦБ. После обрыва связи приложение само переподключается и подтягивает пропущенные донаты.
- Тестовый донат: на 15 секунд добавляет сумму на полосу, чтобы проверить виджет в OBS.
- Окно настроек, значок в трее и одна копия программы. Пока только Linux (AppImage).

## Дорожная карта

От ближайшего к дальнему. Каждый пункт — отдельный проект со своим дизайном и планом в `docs/superpowers/`.

1. **Windows 10/11 и автообновление.** Установщик для Windows и автоматическая сборка выпусков на GitHub. Программа
   сама предлагает обновиться и ставит новую версию только по кнопке.
   [Дизайн](docs/superpowers/specs/2026-11-22-windows-support-design.md).
2. **Общая лента донатов.** Один док для OBS вместо отдельных «последних сообщений» DonationAlerts, DonateX и Meme Alerts.
   Сообщения со всех платформ в одном окне, с меткой платформы.
3. **Очередь оповещений и единый виджет оповещений.** Сейчас алерты с разных платформ играют одновременно и
   перебивают друг друга. В OBS будет один источник оповещений DonateHub. Внутри него работают настоящие виджеты
   DonationAlerts и DonateX, со своими картинками, звуками и голосами озвучки. DonateHub придерживает донаты через
   модерацию DA и задержку DX и отпускает их по одному. Из ленты (п. 2) можно ставить очередь на паузу,
   пропускать и повторять алерты.
4. **Мультичат Twitch + GoodGame.** Чат обеих платформ в одном окне: эмодзи, логотип платформы у каждого сообщения,
   аватарки и значки пользователей.
5. **Meme Alerts.** Донаты через Meme Alerts идут в цель, ленту и очередь. Сами мемы в очередь не встают.
   Публичного API у сервиса нет, поэтому это самый рискованный пункт.
6. **Внешний вид.** Темы приложения, больше шрифтов (системные и свои файлы, а не только список Google Fonts),
   лёгкие анимации цели, которые не нагружают компьютер. Делается небольшими частями между остальными пунктами.

## Установка и запуск (Linux)

Скачайте или соберите `DonateHub-x86_64.AppImage`, сделайте файл исполняемым и запустите двойным кликом
(или `./DonateHub-x86_64.AppImage`). Откроется окно с настройками.

- Закрытие окна сворачивает приложение в трей: донаты продолжают считаться, оверлей в OBS обновляется.
- Клик по значку в трее показывает или прячет окно. Полный выход — пункт «Выход» в меню значка.
- Повторный запуск просто показывает уже открытое окно.
- `--hidden` — запустить сразу в трей, `--headless` — только сервер, без окна.

Порт по умолчанию `47321`. Если он занят, приложение предложит другой. Поменять порт можно и на вкладке
«Подключения». После смены перезапустите приложение и обновите ссылку в OBS и Redirect URL в DonationAlerts.
Переменная окружения `DONATEHUB_PORT` перекрывает сохранённый порт.

Данные (цели, донаты, токены) хранятся в `~/.local/share/donatehub/app.db`. Раньше приложение называлось
«Цель донатов» и хранило данные в `~/.local/share/donation-goal/`. При первом запуске DonateHub эта папка
переносится автоматически.

## Подключение платформ

Всё делается на вкладке «Подключения».

**DonateX.** Скопируйте токен из кабинета DonateX (Настройки → API и доступ), вставьте и сохраните.

**DonationAlerts.**
1. Откройте <https://www.donationalerts.com/application/clients> и создайте приложение.
2. В поле Redirect URL укажите `http://127.0.0.1:47321/auth/da/callback`.
3. Вставьте ID приложения и API ключ на странице настроек и сохраните.
4. Нажмите «Войти через DonationAlerts» и разрешите доступ.

Когда платформа подключена, рядом с ней горит зелёный «Подключено».

## Добавление в OBS

Источники → «+» → «Браузер», URL `http://127.0.0.1:47321/overlay`, ширина 800, высота 200.
Все размеры виджета задаются в `vw`, поэтому он масштабируется вместе с источником.

## Как считается сумма

- В цель идут донаты с обеих платформ с даты старта до даты окончания (или до завершения сбора).
- Суммы в рублях. DonateX сам присылает сумму в рублях. Донаты DonationAlerts в другой валюте
  пересчитываются по курсу ЦБ на день получения.
- Тестовые донаты DonateX в сумму не идут.
- Для денег, пришедших мимо платформ, есть ручная корректировка на вкладке «Текущая цель».

## Разработка

Rust-workspace:
- `crates/core` — сервер (axum), база SQLite, коллекторы платформ, без GUI;
- `src-tauri` — окно (Tauri 2) и трей (ksni).

Фронтенд — чистые HTML/CSS/JS в `static/`, встраивается в бинарник.

```sh
cargo run -p donatehub                  # окно + трей
cargo run -p donatehub -- --headless    # только сервер
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
node --test tests/js
./packaging/build-appimage.sh           # dist/DonateHub-x86_64.AppImage (~115 МБ)
```

Для сборки нужны Rust (stable), системные WebKitGTK 4.1 и GTK3, а при первой сборке — интернет: ставится `tauri-cli`,
Tauri скачивает `linuxdeploy`.

Дизайны и планы реализации всех этапов лежат в `docs/superpowers/specs` и `docs/superpowers/plans`.

## История

- **v0.1.0** — первая версия на Python (FastAPI + PySide6), AppImage ~250 МБ. Код лежит под тегом `python-v0.1.0`.
- **v0.2.0** — переписано на Rust (axum + Tauri) с тем же поведением. AppImage уменьшился до ~115 МБ.
  База данных у версий общая, так что откатиться можно запуском старого AppImage.
